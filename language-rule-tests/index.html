Bilingual bill rules: test images

On a bilingual bill (main language Tamil, second language English in these images):

  • Business name: both languages. English first with the Tamil name under it by default; the setting can put Tamil first.
  • Item name: the main language first, then the second. Swap the two languages and the order swaps. No setting.
  • Business address: one language, English by default; the setting can make it Tamil.
  • Customer name and address: one language, set together by one button: English by default, or Tamil.
  • The three settings are in Settings → Create → Language rules.
  • The title has no Tamil line under it ("Tax Invoice" only).
  • A single-language bill ignores all of this.

Remake the images: in UdukkaiTemplates run npm run dev and open /rules-sheet.html?paper=gst&field=customerName (paper: gst Textiles, coolie Factory; field: businessAddress, customerName, customerAddress, itemName, full; main=en makes English the main language).
