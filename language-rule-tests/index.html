Language rules: every option, as images

Each image prints the same bilingual bill five times, once per option of one rule, cropped to the part of the bill that rule controls. The business is set to main language Tamil and second language English. Option 1 in every image is what the bill prints today with no rule set.

The five options, in order: 1. Default (no rule) · 2. Tamil → English · 3. English → Tamil · 4. Tamil only · 5. English only.

Where Default already equals another option, the two images look the same on purpose (for example the Textiles business name already prints Tamil first, so options 1 and 2 match).

These are renders of the exact bill bundle the app uses. To make them again: in UdukkaiTemplates run npm run dev and open /rules-sheet.html?paper=gst&field=customerName (paper: gst = Textiles, coolie = Factory).
